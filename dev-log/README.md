# Dev log

A running record of decisions and milestones, so future contributors (people
or agents) know not just what was done but **why**.

- One file per entry, named `YYYY-MM-DD-slug.md` (e.g.
  `2026-11-27-prototype-to-static-site.md`).
- Write an entry when a milestone lands or a decision is made that the code
  alone doesn't explain.
- Capture each decision with the reason for it. Link PRs where useful.
- Don't rewrite old entries; if a decision changes, add a new entry that says
  what changed and why.
